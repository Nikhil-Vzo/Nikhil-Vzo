### ⚓ Flagship Production Systems

#### 🌐 [Othrhalff](https://www.othrhalff.in) — *The Verified Campus Connection Network*
> **Status:** Live in Production ([othrhalff.in](https://www.othrhalff.in)) | **Scale:** 400+ Active Campus Users | **Repository:** [`Nikhil-Vzo/Othrhalff`](https://github.com/Nikhil-Vzo/Othrhalff)

* **Architecture:** Full-stack distributed campus platform built with Next.js 14 App Router, TypeScript, and Tailwind CSS on the client; Node.js/Express and Supabase on the backend.
* **Low-Latency Media:** Engineered WebRTC / LiveKit real-time voice and video rooms with sub-100ms connection handshakes.
* **Resilient Data Layer:** PostgreSQL with strict Row-Level Security (RLS), real-time database webhooks, and Redis for distributed session caching and rate-limiting.
* **Autonomous Operations:** Automated GitHub Actions keep-alive workflows to prevent cold-starts and maintain zero-downtime database availability.
* **Dynamic OpenGraph Engine:** Custom Node microservice rendering personalized campus confession and connection preview cards on the fly.
